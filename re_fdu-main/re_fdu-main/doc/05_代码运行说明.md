# 05_代码运行说明

> 本文对应训练营中期材料中的"代码运行说明"。  
> 目标是帮助评审或助教快速理解依赖关系，并尽可能复现当前核心 Demo。

## 1. 项目运行概览

当前 RE:FUDAN 工作版主要由四部分组成：

1. `apps/site`
   - 主站（端口 3000）
   - 包含页面、API、推荐逻辑、A2A 会话逻辑、登录注册逻辑、AI 画像洞察
2. `apps/app`
   - 备用站（端口 3001）
   - 最小化第二个 workspace，启动脚本会一并拉起
3. `packages/contracts`
   - 前后端共享类型
4. `services/profile-extraction`
   - Python 画像抽取与分析流水线
   - 含真实 Chrome + CDP 的小红书登录入口（`xhs_login.py`）

如果只想跑通"主站页面 + 推荐 + A2A 自动多轮"，至少需要：

- Bun
- Node.js（Bun 自带 runtime 也可）
- Upstash Redis
- DeepSeek API Key

如果还想跑通"生成 Agent 档案 / 小红书抓取 / AI 画像洞察"，还需要：

- Python 3.12+
- `services/profile-extraction` 依赖（含 Playwright Chromium）
- 真实 Chrome 浏览器（用于 CDP 附着）

## 2. 环境要求

| 组件 | 建议版本 | 是否必需 | 作用 |
| --- | --- | --- | --- |
| Bun | `>=1.3` | 是 | 安装依赖、运行主站与备用站 |
| Node.js | `>=20` | 是 | Next.js runtime |
| Python | `3.12+` | 画像功能必需 | 运行画像流水线 |
| Playwright Chromium | 最新 | 画像功能必需 | Python 流水线浏览器后端 |
| Google Chrome | 任意 | 小红书 CDP 采集必需 | 真实浏览器登录态来源 |
| Git | 较新版本 | 建议 | 拉取仓库 |

## 4. 一键启动（Windows，推荐）

项目根目录提供 `启动.bat`，在项目根目录双击或在 PowerShell 中执行：

```powershell
.\启动.bat
```

脚本会自动完成 7 步：

| 步骤 | 行为 | 失败时 |
| --- | --- | --- |
| 1/7 | 检查 Bun，缺则自动安装 | 失败时按提示去 https://bun.sh 手动安装 |
| 2/7 | 检查前端依赖，缺则 `bun install` | 网络差时手动重跑 |
| 3/7 | 检查 Python 3.12+ | 缺则按提示装 Python |
| 4/7 | 检查 Python 依赖，缺则 `pip install -r services/profile-extraction/requirements.txt` | 失败时手动安装 |
| 5/7 | 检查 Playwright Chromium，缺则 `python -m playwright install chromium` | 网络差时手动安装 |
| 6/7 | 询问是否打开真实 Chrome 跑 `xhs_login.py` | 选 N 跳过；选 Y 后另开窗口扫码登录 |
| 7/7 | 同时启动 `apps/site`（3000）和 `apps/app`（3001），并自动开浏览器 | 端口被占用时杀掉占用进程 |

脚本结束后会保留两个新窗口：

- `RE:FUDAN site (3000)`
- `RE:FUDAN app (3001)`

> 注意：脚本**不会**自动跑 `bun run seed`。首次跑必须手动执行 seed（见第 8 节），否则学长账号无法登录。

## 6. 配置环境变量

### 6.1 复制模板

```bash
cp apps/site/.env.example apps/site/.env.local
```

Windows PowerShell：

```powershell
copy apps\site\.env.example apps\site\.env.local
```

### 6.2 当前最关键的环境变量

打开 `apps/site/.env.local`，至少补齐：

```env
UPSTASH_REDIS_REST_URL=
UPSTASH_REDIS_REST_TOKEN=
DEEPSEEK_API_KEY=
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1
```

### 6.3 推荐保留：小红书真实 Chrome + CDP

```env
SCHOOLMATE_BROWSER_USE_CDP=true
SCHOOLMATE_CDP_ENDPOINT=http://127.0.0.1:9222
SCHOOLMATE_CHROME_USE_SYSTEM_PROFILE=false
SCHOOLMATE_CHROME_PROFILE_DIRECTORY=Default
```

默认开启后，小红书抓取会通过真实 Chrome 完成，避免 headless 风控。

### 6.4 可选环境变量

```env
GITHUB_TOKEN=
```

说明：

- `GITHUB_TOKEN` 用于提升 GitHub 公开 API 调用速率，未配置时仍可低频抓取

## 7. 云端依赖说明

### 7.1 Upstash Redis

Redis 当前承载：

- 用户信息
- 登录 session（含 role）
- 学长 / 学弟索引
- 推荐缓存
- A2A session metadata
- A2A turn / trace / assessment
- handoff / referral 状态
- chat / inbox 记录

如果 Redis 未配置：

- 登录注册不可用
- 推荐页不可用
- 会话中心不可用

### 7.2 DeepSeek API

DeepSeek 当前用于：

- 学长 Agent 回复生成
- autoplay 自动多轮中的 senior-side 回复
- 会话摘要与 handoff brief 的基础内容
- AI 画像洞察生成（`/api/profile/insights`）

如果 Key 未配置：

- 页面可以打开
- A2A 生成与画像洞察会回退到 fallback 输出

如果 DeepSeek 临时不可达：

- A2A 会显示 fallback reply
- AI 画像洞察会回退到本地 fallback 归纳

## 11. 小红书真实 Chrome + CDP 登录

### 11.1 启动登录窗口

启动脚本第 6 步选 Y 会自动跑；也可以手动：

```bash
cd services/profile-extraction
python xhs_login.py
```

会发生什么：

1. 启动一个带 `--remote-debugging-port=9222` 的真实 Chrome
2. 自动打开小红书首页
3. 你在 Chrome 中**手动登录**（扫码 / 验证码）
4. Python 验证可以通过 CDP 端点附着到这个浏览器
5. CDP 端点信息写入 `services/profile-extraction/data/chrome_cdp_endpoint.txt`

### 11.2 注意

- 这个 Chrome 窗口请**保留在后台运行**，不要关闭
- 关闭后下次抓取需要重新跑 `xhs_login.py`
- 浏览器登录态可能保存在 `services/profile-extraction/data/browser_profile/`，**不要提交到仓库**

### 11.3 Mac / Linux

`xhs_login.py` 默认 Chrome 路径列表为 Windows 标准路径，Mac / Linux 用户需要手动指定 Chrome 可执行路径，或修改脚本里的 `CHROME_CANDIDATES`。

## 12. Python 流水线说明

画像流水线位于：

- `services/profile-extraction`

它不是单独的 HTTP 服务，而是被主站通过 Node 子进程调用。

调用入口：

- `apps/site/src/lib/python-bridge.ts`

### 当前支持的资料来源

- GitHub
- 小红书（CDP 真实浏览器路径）
- 知乎
- LinkedIn

### 输出位置

- `services/profile-extraction/outputs/`
- 主站会将结构化 `builtProfile` 写回 Redis

## 13. 推荐运行验证顺序

为了减少排错时间，建议按以下顺序验证。

### 第一步：验证主站能打开

访问：

- `/`（双角色落地页）
- `/signup?role=junior`
- `/login`

### 第二步：验证 Redis 读写正常

执行：

```bash
cd apps/site
bun run seed
```

然后：

- 使用 demo 学长账号（`chensirui / demo123` 等）登录
- 检查是否 SSR 自动跳到 `/me/senior`

### 第三步：验证推荐与 A2A 自动多轮主链路

使用学弟账号：

1. 落地页注册学弟账号
2. SSR 跳到 `/me/junior`
3. 选择一个问题方向
4. 在推荐卡片中输入第一句问题
5. 启动 A2A 自动多轮
6. 检查是否出现：
   - 自动推进状态
   - summary / verdict / adjustedScore
   - "查看完整 A2A"入口

### 第四步：验证 P3 和 handoff

1. 进入 `/a2a/[sessionId]`
2. 检查自动轨迹是否存在
3. 切换到学长账号
4. 在 `/me/senior` 查看接力收件台
5. 完成 handoff 审批
6. 进入 `/a2a/[sessionId]/referral` 看 P4 简报

### 第五步：验证 Python 画像流水线 + AI 洞察

在 `/agent-workbench`：

1. 输入 GitHub 用户名或其他社媒账号（小红书需要先跑 `xhs_login.py`）
2. 点击"生成我的 Agent"
3. 检查是否返回结构化档案
4. 检查 `/api/profile/insights` 是否返回画像洞察卡（`source` 字段会标 `ai` 或 `fallback`）

## 16. 常见问题

### 问题 1：主站能打开，但登录注册报错

大概率原因：

- Redis 未配置
- `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` 缺失

### 问题 2：登录后没跳到工作台 / 一直停在 `/me`

大概率原因：

- 没跑 `bun run seed`，学长账号根本不存在
- 用户的 `role` 字段缺失，按 SSR 默认会跳到 `/me/junior`

### 问题 3：A2A 只回一轮就停住

请优先检查：

- 是否在 `/me/junior` 或已兼容后的 `agent-workbench` 路径触发
- 浏览器是否成功调用 `/api/a2a/sessions/[sessionId]/autoplay`
- Redis 中 session metadata 是否写入了 `autoplayState`
- DeepSeek 是否可达（看浏览器 devtools 网络面板）

### 问题 4：前端显示 fallback reply

大概率原因：

- DeepSeek 网络请求失败
- 模型提供方暂时不可用

此时系统可能继续运行，但会使用保底回复。

### 问题 5：画像洞察卡片标着 `source: fallback`

说明 DeepSeek 调用失败了，系统已切到本地归纳。
- 检查 `DEEPSEEK_API_KEY` 是否正确
- 检查 builtProfile 是否完整（fallback 会基于现有字段尽力归纳）

### 问题 6：点击"生成我的 Agent 档案"失败

大概率原因：

- Python 未安装或版本低于 3.12
- 虚拟环境依赖未安装
- Playwright Chromium 没下载
- 外部采集源访问失败

### 问题 7：小红书抓不到内容

大概率原因：

- `xhs_login.py` 没跑，或 Chrome 窗口已经关闭
- `SCHOOLMATE_CDP_ENDPOINT` 端口与实际不一致（默认 `9222`）
- 当前登录态过期，需要重新登录

### 问题 8：3000 / 3001 端口被占用

大概率原因：

- 之前的 dev server 没关
- 解决：任务管理器关掉占用进程，或修改 `apps/site/package.json` / `apps/app/package.json` 的端口
