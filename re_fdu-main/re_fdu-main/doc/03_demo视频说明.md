# 03 · Demo 视频说明（含录制脚本）

> 本文档既是演示视频脚本，也作为提交材料 `03_Demo视频说明.md` 直接交付。
> 目标时长：3-5 分钟。建议用 OBS Studio / Windows Game Bar / Mac QuickTime 录屏。

---

## 录制前准备清单

- [ ] 完成 SecondMe 个人分身训练，profileCompleteness ≥ 50%（影响回答质量）
- [ ] 删除 `apps/site/mentor_tokens.json`（让所有 mentor 回到"待绑定"初始状态）
- [ ] dev server 已启动 (`bun run dev`)
- [ ] 浏览器开启**无痕模式**（避免历史记录干扰）
- [ ] 准备好 1 个**简短的问题文本**便于复制：
  > "学长好，我想问下保研到 NLP 方向的夏令营，简历里实验室经历应该怎么呈现比较好？"
- [ ] 录屏分辨率 1920×1080，30fps，麦克风测试

---

## 推荐场景顺序（4 分钟版本）

### 场景 1：开场与产品定位（0:00 - 0:30）

**录什么**：
- 落地页 http://localhost:3000，停留 5 秒展示标题"让经验先抵达，答案再相见"
- 缓慢滚动展示三个 grid card（Path-first matching / A2A pre-conversation / Human-approved handoff）

**说什么**（旁白）：
> "RE:FUDAN 复见，是一个面向复旦校园的 Agent-Native 社交演示系统。我们的核心理念是『让经验先抵达』——通过 AI 数字分身，让学长学姐的经验和学弟妹的提问，先完成一次高质量的低摩擦对话，再决定是否真人见面。本项目所有学长学姐资料**均经本人授权，不进行任何爬取**。"

---

### 场景 2：学长授权流程（0:30 - 1:30）

**录什么**：
1. 顶部导航点击 "Onboard" → 进入 `/mentor-onboard`
2. 展示 6 张 mentor 卡片，**重点突出黄色徽章"本人已同意 · 待 SecondMe 绑定"**
3. 在陈晓远卡片点击 "**开始 SecondMe 授权**"
4. 浏览器跳转到 `go.second-me.cn/oauth/...`，**展示 SecondMe 标准授权页**
5. 同意授权
6. 回调到 `/mentor-onboard?status=success`，**绿色 banner 出现**："✅ 已绑定..."
7. 陈晓远卡片状态变为绿色"**SecondMe 分身已接入**"，下方显示 secondme userId 和绑定时间

**说什么**：
> "首先看学长侧的授权流程。每位 mentor 都必须在 SecondMe 平台**完成自己分身的训练**，然后通过标准的 OAuth2 授权码流程，把分身能力授予 RE:FUDAN。
>
> 注意视频中演示绑定的是项目方账号——出于中期演示阶段时间限制，此 mentor 卡片绑定项目组成员自己的 SecondMe 账号，用于验证完整 OAuth2 链路与流式对话技术可行性。
>
> 正式上线时，该 mentor 将由本人独立完成相同的授权流程。"

**关键画面**：
- SecondMe 平台真实授权页（证明这是真实 OAuth2 流程，不是 mock）
- 回调后状态徽章变绿
- 显示 secondme_user_id（如 `asu_8a33c194...`）证明 token 已落地

### 场景 3：学弟妹查询与 A2A 对话（1:30 - 3:00）

**录什么**：
1. 顶部导航点击 "Mentors" → 进入 `/mentors`
2. 展示 6 张 mentor 雷达图卡片
3. 鼠标 hover 到刚才授权的陈晓远卡片，**展示绿色"SecondMe 分身已接入"小标签**
4. 点击 "**让我的 Agent 去聊聊**" → 进入 `/agent-workbench?mentor=chenxiaoyuan`
5. **顶部合规水印展示给评审看**："本工作台中由 SecondMe 分身... AI 助手代为表达..."
6. 在 match 区对话框粘贴准备好的问题
7. 按回车 → **展示流式回复的动态过程**（这是 demo 的高光时刻）
8. 等待回复完成，展示完整回复

**说什么**：
> "切换到学弟妹视角，浏览推荐学长。雷达图从院校匹配、专业匹配、目标重合、经历相似四个维度展示路径相似度。
>
> 进入对话工作台后，**顶部合规水印持续提示这是 AI 代为表达**，非本人直接发言。
>
> 现在我以学弟身份向陈晓远学长发问——可以看到回复来自经本人授权的 SecondMe 真实分身，流式生成。"

**关键画面**：
- 顶部合规水印（必须清晰可见）
- 流式打字效果（如果回复一次性出现，可在剪辑时强调"端到端 9 秒响应"）
- 完整回复内容

## 录制 Tips

1. **不要光说"看看这里" "看看那里"**——每个鼠标点击都明确说**为什么点这个**
2. **关键操作前停顿 1 秒**，让评审看清画面
3. **页面切换时口播保持连贯**，不要出现停顿
4. **重要术语首次出现时停顿一下**：A2A、OAuth2、SecondMe、合规水印
5. **顶部合规水印必须特别拉一下注意力**——这是评分加分项
6. 如果回复太慢（>10 秒），剪辑时可以加速 1.5x 或剪掉

## 后期剪辑要点

- 字幕：建议加上所有旁白字幕（评审老师可能不戴耳机看）
- BGM：可以加一段轻柔背景音乐（音量 < -20dB），但不是必须
- 起止画面：开头 0.5 秒黑屏 + 项目名称卡片；结尾 1 秒黑屏 + 项目链接
- 导出：H.264 编码，1080p 30fps，10-50MB 之间，文件名 `02_demo_video.mp4`

## 录完之后

1. 在浏览器全屏播放一遍**自查**：声音是否清晰、画面是否流畅、有无敏感信息（API key/密码）泄露
2. 如发现敏感信息泄露 → 必须重剪那一段
3. 文件命名为 `02_demo_video.mp4`，放入提交压缩包根目录
